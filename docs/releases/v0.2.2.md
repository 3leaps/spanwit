# spanwit v0.2.2

## Overview

A report-contract and release-hardening release. Every report names the tool
that wrote it, and every byte figure states its bound: exact, lower, upper,
or unknown. `space` explains container engine storage and agent tool state,
and recognizes more rebuildable caches. Publish verifies against identities
pinned in the tagged commit. Deletion remains dry-run by default.

## Highlights

- **Report envelope and bounds**: every whole-document report carries `$schema`, version, `generated_at`, `tool`, `completion` and disclosure. Every byte figure states its bound (`exact`, `lower`, `upper` or `unknown`). Exact prune plans have a published schema.
- **Container headroom**: `space --containers` reports container engine storage by kind, and relief steps ordered from rebuild, through re-pull, to data-loss risk. It reads the local Engine API and does not run those steps. `--probe-vm` measures the VM data disk from inside.
- **New reclaim signatures**: interrupted grype database downloads and repo-local Go build caches are recognized with evidence. `--include-temp` opts in to walking the per-user temp directory under strict admission.
- **Agent tool state**: Codex, Grok CLI and OpenCode data appear as diagnostic-only hotspots, with a print-only recipe for superseded Codex releases.
- **Safer age gates**: a configured `min_age` reads the newest activity inside a candidate, and `space --config` applies the config's default gates.
- **Publish checks**: publish trusts only the pins committed in the tagged commit, CI artifacts are bound by id and digest, and signature verification fails closed.

## Release provenance

- Release tags are GPG-signed and verify against [`docs/security/release-signing-keys.asc`](../security/release-signing-keys.asc) (fingerprints in [`keys/expected-fingerprints.txt`](../../keys/expected-fingerprints.txt)). Verify with `git tag -v v0.2.2` after importing that key.
- Checksum manifests are signed with minisign and PGP; the published assets are byte-identical to the signed set.
